# mattmaltman.github.io

Personal research website for Matthew Maltman: https://mattmaltman.github.io

`index.html` is generated. To update the site, edit `build/data.json` (entries) or `build/template.html` (layout and styles), then run:

```
python3 build/build.py
```

Charts are drawn at build time as inline SVG from the CSVs in `build/figures/`.
